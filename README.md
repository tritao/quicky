# Tricky Quiky Games II reverse engineering

Research repository for continuing Simon Laburda's reverse engineering of the
1995 MS-DOS game Tricky Quiky Games II / Nesquik / Quiky.

The technical report, verified archive layout, source-derived tool syntax,
portable archive utilities, MAP/ICO/PCC notes, and DOSBox workflow are in
[research/README.md](research/README.md).

This repository intentionally does not track downloaded game archives,
extracted game assets, or generated binaries. See the report for the original
DKIA and DOSGames sources and reproducible retrieval/build instructions.
